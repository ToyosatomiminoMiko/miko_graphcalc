# 微分方程使用指南

本文是**用户视角**的用法说明:在 GraphCalc 里怎么用 `ode` 语句解微分方程,
怎么读斜率场与解族,怎么看推导过程,以及哪些方程当前算不出来.设计与分期见
[三期完整规划与设置](plan3.md),总口径见
[不定积分与微分方程:设计计划](calculus-suite-plan.md).

---

## 1 一条语句:ode

```text
ode 名称 = 方程[, 初值...] { 选项; };
```

- `名称` 是这条语句的名字,也是它下发实体的名字前缀(见第 3 节);
- `方程` 必须含**导数记号**(`y'` / `y''`),并写成 `左边 = 右边`.整段方程按
  **首个顶层 `=`** 分左右,按**首个顶层逗号**切出方程与各条初值(括号内的逗号
  不参与切分),所以 `f(x, y)` 这类函数调用不会写坏;
- 初值每条写成 `y(0) = 1` / `y'(0) = 1`,直接跟在方程后,用逗号分隔;
- 选项放在 `{ }` 里,每条选项以 `;` 结尾,整条语句最后再写一个 `;`.

和 `antiderivative` 一样,一条 `ode` 语句同时是**求值条目**与**实体来源**:

1. **求值条目**:底部"求值对象"栏的"微分方程"子列表多一条,摘要就是原方程;
   展开可见通解/特解/初值回显/斜率场/回代验证/如实说明,点行末"过程"在右栏
   过程页逐步翻看;
2. **实体对象**:它下发的斜率场与解曲线出现在实体列表与三维视口里,是可被
   `derivative`/`integral` 引用的普通对象(见第 3 节).

六个可直接粘贴的例子:

```miko
// 1. 一阶可分离:通解 y = C*exp(x^2/2),斜率场与解族同一来源
ode S = y' = x*y;

// 2. 一阶线性 + 初值 + 参数:积分因子求解,拖滑块特解曲线跟着动
param p = 1 in [0, 3, 0.1];
param q = 2 in [0, 5, 0.5];
ode L = y' + p*y = q, y(0) = 1;

// 3. 二阶常系数齐次 + 两个初值:特征方程给出两个相异实根
ode H = y'' - 3*y' + 2*y = 0, y(0) = 0, y'(0) = 1;

// 4. Bernoulli:换元 u = y^{1-n} 化为一阶线性
ode B = y' = y - y^2;

// 5. 解族 + 域:前两个数是曲线区间,四个数同时给斜率场域
ode F = y' = 2*x*y^2 { curves = 5; range = [-2, 2, -2, 2]; };

// 6. 隐式解:过程页与细节照实排隐式,不画解曲线
ode I = y' = 1/(y^2+1);
```

方程里的 `y'` 必须是一次的:像 `(y')^2 = x` 这样 `y'` 非线性出现会走能力边界,
连斜率场也不下发;`y'` 是一次式但不在可解清单里(如 `y' = x + y^2`)仍会下发
斜率场.`y'''` 及以上直接报错(见第 8 节).

## 2 选项

选项白名单共 7 项,写错或重复会**编译期报错**,不会静默用缺省值:

| 选项 | 含义 | 缺省 |
| --- | --- | --- |
| `dependent` | 因变量名 | 从导数记号推断(如 `y'` -> `y`) |
| `independent` | 自变量名 | 从方程里的坐标变量推断(`x`/`t`) |
| `constant` | 解族第一条曲线的积分常数取值(**只对一阶生效**) | `0` |
| `curves` | 画几条解曲线,非负整数,上限 12 | `0`(只画斜率场) |
| `range` | 曲线/斜率场的域,**2 个或 4 个数** | 曲线 `[-8, 8]`,斜率场 `[-6, 6, -6, 6]` |
| `segments` | 采样分段数 | 继承渲染器默认(曲线 320,斜率场 64) |
| `color` | 颜色 | 调色板 |

`range` 的两种写法含义不同:

- **2 个数** `range = [-2, 2]`:只给**解曲线**的定义域;斜率场仍用自己的缺省域
  `[-6, 6, -6, 6]`(想让它变小就写 4 个数);
- **4 个数** `range = [-2, 2, -2, 2]`:写成 `[xmin, xmax, ymin, ymax]`,解曲线取
  前两个数作区间,斜率场用全部四个数.两个区间都必须 `min < max`.

`constant` 只影响一阶解族里**第一条**曲线(`C` 的取值);它不参与二阶解族的
取值口径(见下一节).`curves` 超过 12 会被截到 12.

## 3 下发的实体:斜率场与解曲线

一条 `ode` 语句最多下发三类实体,命名口径固定:

| 实体名 | 角色 | 何时下发 |
| --- | --- | --- |
| `名称` | 斜率场,`surface z = f(x, y)`(一阶方程的右端) | 一阶方程(含超出能力边界但 `y'` 是一次式的一阶方程);**二阶没有斜率场** |
| `名称_p` | 由初值定出的特解,`curve y = ...` | 写了初值,能定出常数,且通解是显式形式(隐式解只给 `Φ(x,y) = C0`,不下发此曲线) |
| `名称_c1`,`名称_c2`... | 解族成员,从 `c1` 开始编号 | `curves > 0` 且通解是显式形式 |

它们都登记进可引用对象表,所以下面这些写法成立:

```miko
ode S = y' = x*y, y(0) = 1 { curves = 3; };
derivative D = derivative(S, x);                    // 对斜率场 z = x*y 求偏导(曲面必须给变量)
derivative d = derivative(S_p);                     // 对特解曲线求导(曲线缺省对 x)
integral I = integral(S_c1) { range = [-1, 1]; };   // 对一条族曲线做定积分
```

### 解族与常数取值

- **一阶**用单个常数 `C`:第一条曲线取 `constant`(缺省 `0`),其后按
  `+1, -1, +2, -2, ...` 依次取,去重后截到 `curves` 条;
- **二阶**用一对常数 `(C_1, C_2)`:先取两个基解 `(1,0)`,`(0,1)`,再取
  `(1,1)`,`(-1,1)`,`(1,-1)`,`(-1,-1)`;还不够就把整组乘 `2, 3, ...` 继续取
  (条数始终与 `curves` 一致).二阶的 `constant` 选项被忽略,因为一对常数没法
  由单个数值指定.

**一族同色**:一条语句下发的所有解曲线共享同一种颜色;斜率场默认取调色板里
**另一种**颜色,便于区分"场"与"族".若显式写了 `color`,斜率场与解曲线都用该色.

## 4 能算哪些:能力清单

内核走的是"可解类型清单",一类一类判定;覆盖范围:

| 类别 | 例子 |
| --- | --- |
| 一阶可分离 | `y' = x*y`,`y' = 2*x*y^2`,`y' = 1/(y^2+1)`(三次方程解不出 `y`,给隐式解) |
| 一阶线性(积分因子) | `y' - y = x`,`y' + p*y = q`(参数保持符号);右端只含 `x` 时直接积分,如 `y' = x^2` |
| Bernoulli | `y' + y = y^2`,`y' = y/x + x*y^2`,`y' + p*y = q*y^2` |
| 一阶齐次 | `y' = (x^2 + y^2)/(x*y)`,`y' = (2*x*y)/(x^2 - y^2)` |
| 一阶恰当 | `(2*x*y + cos(x)) + (x^2 + y)*y' = 0` |
| 二阶常系数齐次 | `y'' - 3*y' + 2*y = 0`;实根/重根/共轭复根三型 |

**算不出来的走能力边界**,条目保留在列表里并给出理由,但不下发解曲线
(一阶且 `y'` 是一次式时仍会下发斜率场):

| 输入 | 结果 |
| --- | --- |
| `y'' + y = sin(x)`(二阶常系数非齐次) | "二阶常系数非齐次方程暂不在内核能力内(设计文档 4.3):请先做齐次方程" |
| `y'' + y^2 = 0`,`y'' + sin(y) = 0` 等非线性项 | "方程不是二阶常系数线性形式:内核只支持 a·y'' + b·y' + c·y = 0" |
| `y'' + x*y = 0`(变系数二阶) | "二阶常系数齐次方程要求系数 c 是数值:符号系数下特征根类型无法判定,请把系数写成数值" |
| `(y')^2 = x`(`y'` 非线性出现) | "方程里 y' 不是线性出现的:内核只支持 y' 的一次式" |
| 各分支都判定不上(如 `y' = x + y^2`) | "超出内核能力:不在可解清单内(可分离 / 一阶线性 / 伯努利 / 齐次 / 恰当 / 二阶常系数齐次)" |

有些清单外输入会命中更具体的理由(如 `y' = sin(x^2)` 报积分内核给出的原函数
说明),不一定是上面最后那条通用文案;共同点是都走 `error`,都不是源码错误.

**二阶常系数要求系数是数值**.`a·y'' + b·y' + c·y = 0` 里的 `a`/`b`/`c` 必须
是数值常数:符号系数下无法判定特征根类型,内核走能力边界而不是猜:

```miko
param a = 1 in [0.5, 3, 0.1];
ode Bad = a*y'' + y' + y = 0;   // error:要求系数 a 是数值
```

注意"能力边界"不是源码错误:方程本身写得没错,只是内核没覆盖.`y'''` 超二阶,
未声明符号,初值写错才是真正的输入错误,见第 8 节.

## 5 隐式解

有些方程只能积成隐式通解(如 `y' = 1/(y^2+1)` 积出 `y^3/3 + y = x + C`),这时:

- 过程页与细节给出的是 **`Φ(x, y) = C`**,并明确标注
  "通解是隐式解(Φ(x,y) = C),不是 y = ... 的显式形式";
- **不画解曲线**:`Φ(x,y) = C` 没法直接当 `y = f(x)` 采样,此时细节里会照实给出
  内核的说明(如"通解是隐式形式 ...:内核未能把它解成 y(...),暂不按下发解曲线"),
  不会静默画出错误曲线;
- 隐式解**写了初值**时,初值只用来把常数定成 `C0 = Φ(x0, y0)`,特解照实写成
  `Φ(x, y) = C0`,**同样不下发** `名称_p` 曲线.

内核会先尝试把积分结果**显式化**,能解出 `y` 就照显式给:

- 对 `y` 的**一次式** `k·y + b = T` 直接反解;
- 套函数取反:`ln`/`exp`,`tan`/`atan`,`sin`/`asin`,`cos`/`acos`,
  `sqrt`(平方),`sinh`/`asinh`,`cosh`/`acosh`,`tanh`/`atanh`,以及常数因子的
  缩放;`∫dy/y` 留下的 `ln|y|` 会剥掉绝对值(`C` 天然吸收正负号);
- 幂函数 `u(y)^n = T` 开 `n` 次方反解.

之外(积分结果里因变量被套在无法整体反解的复合结构里)就照实保留隐式,不硬解.

## 6 参数与自变量

**参数保持符号**:`ode` 只把参数**名字**交给内核,解里的参数原样留着,数值由
物化层按当前滑块折叠.所以拖滑块时解与曲线实时联动,不会冻在声明值:

```miko
param a = 2 in [0.5, 3, 0.1];
ode P = y' = a*y;              // 通解 y = C*exp(a*x),a 仍是符号
```

两个例外:二阶常系数要求系数是数值(见第 4 节);**初值点必须是数值**,
初值右端不能含因变量,但**可以含参数**--一阶会把常数定成含参数的表达式
(拖滑块时特解跟着变,如 `y(0) = a`),二阶的二元一次方程组则需要数值初值,
含参数时只给通解并在细节里说明"无法定出积分常数".

**自变量/因变量推断规则**:

- 因变量缺省取带导数记号的符号(`y'` -> `y`);一个方程只能有一个因变量,
  出现两种导数记号(如同时有 `y'` 与 `z'`)报错;
- 自变量缺省从方程里出现的坐标变量推断:**只有 `x` 或只有 `t`** 时取它;
  **一个都没有**时按缺省自变量 `x` 处理,并在细节里留一条明文说明;
  **`x` 与 `t` 同时出现**时无法推断,报错要求用 `independent` 指定;
- `dependent`/`independent` 选项可显式覆盖;自变量与因变量同名报错.

```miko
// 方程里没有坐标变量,显式指定自变量的写法
ode T = y' = y { independent = t; };
```

渲染层只认 `x`/`y`:内核产出的自变量/因变量名会被换成 `x`/`y` 再下发,所以
`ode T = u' = t*u { independent = t; dependent = u; };` 的曲线在视口里仍画成
`y = f(x)`.

## 7 过程页怎么看

点条目行末"过程",右栏过程页标题是 `微分方程 名称`,题目区就是原方程.步骤链
由内核给出,**不单独排一行"分类"**,分类体现在各分支专属的第一步里:

- **一阶线性**:写成 `y' + p(x)y = q(x)` 标准形 -> 积分因子 `μ = e^{∫p dx}` ->
  `(μy)' = μq` -> 两侧积分 -> 解出通解;右端只含 `x` 时第一步就是"右端只含
  自变量:直接积分";
- **一阶可分离**:分离变量 `(1/g)dy = h dx` -> 两侧积分 -> "解出通解",或反解
  不出时"积分得隐式通解";
- **Bernoulli**:伯努利换元 `u = y^{1-n}` -> 化为线性方程 -> 积分因子 ->
  线性方程的通解 -> 换元回代得通解;
- **一阶齐次**:判定为齐次方程 -> `u = y/x` 的代换 -> 化为可分离 -> 换元回代;
- **一阶恰当**:恰当方程判定(`∂M/∂y = ∂N/∂x`)-> 求势函数 -> "解出通解"或
  "隐式通解";
- **二阶常系数齐次**:标准形 -> 特征方程 -> 判别式 -> 特征根 -> 按两相异实根/
  二重实根/共轭复根写出形状与通解.

写了初值时,通解之后追加:"代入初值"-> "解出积分常数"(二阶是两个初值一起代
入的方程组)-> "代入常数得特解".最后固定是**回代验证**一步:显式解给出
`y' = ...` 代回原方程;隐式解给出 `Φ_x + Φ_y f(x, y) = 0, 代回原方程成立`.

这不是装饰:内核在放行前会对自己给出的解**抽样回代对拍**(隐式解走隐函数求
全导),不一致就拒绝,条目显示"内核给出的解未通过回代验证,已拒绝(请报告这条
方程)",不会给出可疑的解.细节区另外如实回显:初值原文,是否隐式解,未定出
常数,缺省自变量,下发了几条解曲线,共几步.

## 8 常见报错与排查

| 现象/报错 | 原因与处理 |
| --- | --- |
| "微分方程含未声明符号 k" | 方程里的 `k` 不是坐标变量/因变量/导数记号.用 `param k = ...;` 声明,或检查拼写 |
| "初值重复"(`初值重复:... 描述的是同一个初值`) | 同一位初值写了两次.一阶只能有一条 `y(x0) = y0`;二阶要 `y(x0)` 与 `y'(x0)` 各一条(两点不同时可以编译,但定不出常数,只给通解并说明) |
| "初值条件 ... 必须写成 y(x0) = y0 或 y'(x0) = y0 的形式" | 初值左端必须是 `因变量(点)`,不能写成 `y = 1` 或 `y(0)` |
| "初值点 ... 需要是数值" | 初值点必须是数值常数;右端可以含参数,但不能含因变量(见"初值 ... 的右端不能含因变量 y") |
| "一阶方程只接受 y(x0) = y0 形式的初值" | 一阶方程写了 `y'(x0) = v0`;那属于二阶 |
| "二阶方程需要两个初值" | 二阶只写了一条初值;要 `y(x0) = y0` 与 `y'(x0) = v0` 两条 |
| "导数记号 y''' 超过二阶,内核只支持一阶与二阶方程" | 降阶后再求解 |
| "符号 yp 与导数记号 y' 的归一化名冲突,请改用其他符号名" | 源码里自己用了 `yp`/`ypp`(导数记号归一后的名字).换名 |
| "方程里同时出现了 x 与 t,无法推断自变量" | 用 `independent = x`(或 `t`)显式指定 |
| "自变量与因变量不能同名" | 换一个自变量名 |
| "方程里没有出现导数记号" | 写的是普通方程;微分方程至少要有一个 `y'` |
| 隐式解"不画解曲线" | 通解是 `Φ(x,y) = C`,不能直接采样;这是如实说明,不是 bug |
| "微分方程 X 包含未知选项: foo"/"微分方程 X 包含重复选项: foo" | 选项名写错或重复;白名单见第 2 节 |
| "微分方程 X 重复声明"/"对象 X 重复声明" | 同名 `ode` 语句写了两条,或下发的实体名(`X`/`X_p`/`X_c1`...)与已有对象重名 |

## 9 限制与后续(四期)

当前版本刻意保守,以下都**还没有**:

- 斜率场是"高度图"`z = f(x, y)`,**没有**方向场短线/箭头的专用渲染器;
- 隐式解只在公式与说明里出现,**没有**等值线/marching 渲染;
- 二阶常系数**非齐次**,可降阶二阶(`y'' = f(x)` / `y'' = f(y)`)等尚未进
  内核;
- **没有**参数曲线 `(x(t), y(t))`,也**没有**方程组与相图.

四期的收尾与增强项(文档收尾,体积优化,非齐次二阶,可降阶二阶,隐式解可视化,
方向场渲染器,参数曲线,方程组与相图)按优先级列在
[三期完整规划与设置](plan3.md) 第 2 节.
