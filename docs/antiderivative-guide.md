# 不定积分使用指南

本文是**用户视角**的用法说明:在 GraphCalc 里怎么求原函数,怎么看推导过程,
以及哪些函数当前算不出来.设计与分期见
[不定积分与微分方程:设计计划](calculus-suite-plan.md).

---

## 1 一条语句:antiderivative

```miko
curve f = x^2 + sin(x) { range = [-4, 4]; };
antiderivative F = antiderivative(f);
```

`F` 有**两个身份**:

1. **求值条目**:「求值对象」窗口里多一条"原函数 F",展开可见通解 `F + C`,
   常数取值,回代验证与步骤计数;点行末"过程"在过程窗口里逐步翻看;
2. **实体对象**:`F` 同时是一条普通曲线(源是 surface 时是曲面),出现在实体
   列表与三维视口里,颜色/定义域/分段数默认继承源对象.

正因为它是普通对象,下面这些都能直接对它用:

```miko
derivative back = derivative(F);          // 对原函数再求导 -> 回到 f
gradient g = grad(F) at [1, 0];           // 原函数在某点的切线斜率 = f(1)
integral I = integral(F) { range = [-1, 2]; };  // 原函数的定积分
```

`example/antiderivative_basic.miko` 就是"求原函数 -> 再求导 -> 与源曲线重合"
的最小闭环(微积分基本定理的图形版).

---

## 2 选项

| 选项 | 含义 | 缺省 |
| --- | --- | --- |
| `constant` | 积分常数取值,**并入下发对象的表达式** | `0` |
| `range` | 下发对象的定义域(曲线 2 个值,曲面 4 个值) | 继承源对象 |
| `segments` | 采样分段数 | 继承源对象 |
| `color` | 颜色 | 继承源对象 |
| 第二个参数 | 积分变量(只写 `x` 或 `y`;curve 只能是 `x`) | `x` |

关于 `constant`:展开细节里永远写符号 `+C`(做题写的是通解),而实体曲线画的是
`F + 常数`.想看不同的常数把曲线上下平移,改 `constant` 或把它绑到参数上:

```miko
param c = 0 in [-5, 5, 0.5];
antiderivative F = antiderivative(f) { constant = c; };
```

---

## 3 参数与曲面

参数在原函数里**保持符号**,并跟随滑块实时变化:

```miko
param a = 2 in [0.5, 3, 0.1];
curve f = a*x^2 + sin(x);
antiderivative F = antiderivative(f);   // F 的表达式里仍是 a
```

曲面可以指定对 `y` 积分(另一个坐标 `x` 被当作常数):

```miko
surface s = x*y^2;
antiderivative G = antiderivative(s, y);   // G = x*y^3/3
```

## 4 能算哪些:能力清单

内核走的是"系统化初等积分",覆盖范围:

| 类别 | 例子 |
| --- | --- |
| 幂与多项式 | `x^7`,`3*x^2 - 4*x + 5`,`1/x`,`1/(3*x-2)`,`(5*x+4)^3`,`sqrt(x+1)` |
| 指数与对数 | `exp(2*x)`,`ln(x)`,`x*ln(x)`,`x^2*ln(x)` |
| 三角(含线性内核) | `sin(3*x+1)`,`cos(x/2)`,`atan(x)`,`asin(x)` |
| 三角幂 | `sin(x)^2`...`sin(x)^5`,`cos(x)^2`...`cos(x)^5` |
| 有理函数 | `1/(x^2-4)`,`1/(x*(x+2))`,`1/(x-1)^3`,`(3*x+2)/(x^2+4)`,`x/(x^2+1)`,`1/(x^2-x+1)`,`(x^2+2*x+3)/(x+1)` |
| 根式与反三角基本形 | `1/sqrt(1-4*x^2)`,`1/(9+x^2)`,`sqrt(1-x^2)`,`1/(4-x^2)` |
| 分部积分 | `x*exp(x)`,`x^2*exp(x)`,`x*sin(x)`,`x*cos(x)` |

**算不出来的会明确报错**,绝不给出错误原函数:

| 输入 | 结果 |
| --- | --- |
| `exp(x^2)` | "e^{x^2} 的原函数是误差函数...请改用 integral 的数值方法" |
| `sin(x^2)` | "...是 Fresnel 积分..." |
| `exp(sin(x))` | "无法给出 ... 的原函数(超出内核的初等积分规则)" |
| 含未声明符号 | "被积函数含未声明符号 a:请用 param 声明参数..." |

这两种情况的差别很重要:前两者是**数学上不是初等函数**,后者是**规则没覆盖到**.
无论哪种,条目都会保留在列表里并给出理由,但**不会下发曲线**(算不出原函数就
没有东西可画).

## 5 怎么确认答案是对的

每一条成功的原函数,过程页最后一步固定是**回代验证**:

```
d/dx [ F ] = f
```

这不是装饰:内核在给出结果前会对它再符号求导,与被积函数抽样对拍,不一致就
直接拒绝并报"未通过回代验证".Rust 侧对每个类别都有断言测试
(`math_rs::symbolic::integral::tests`),包括上面清单里的每一类.

课堂上更直观的做法是再加一条 `derivative` 语句,让两条曲线在视口里重合.

---

## 6 与 `integral`(定积分)的关系

- `antiderivative`:符号原函数,结果是**表达式 + 曲线**;
- `integral`:数值定积分,结果是**数值 + 黎曼/梯形/辛普森/勒贝格可视化**,
  域可以是区间/矩形/区域/实体.

两者互补:内核算不出原函数时,定积分仍然可以数值算(这正是报错文案里给出的
指引).要演示牛顿-莱布尼茨公式,用 `antiderivative` 拿到 `F` 后写两条
`gradient` 分析读 `F(a)`/`F(b)`,再与 `integral` 的数值对照即可.
